# Shipwright 0.1.2 — Dedicated size comparison

Moves size comparison into its own dialog with a common comparison scale independent of canvas zoom.

## Decisions

I found that comparison artwork competed with the editing surface. I wanted the comparison available on demand.

## Archive status

Retrospectively published prototype. Changes were checked against retained runtime snapshots. This archive preserves compiled application files; original TypeScript is not reconstructed. It does not inherit the 2.0.0 regression results. Use 2.0.0 for current work.
